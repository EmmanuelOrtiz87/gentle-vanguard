# Gentle-Vanguard Design System v2 — DESIGN.md

> Canonical design reference for all Gentle-Vanguard apps. Follows Google DESIGN.md spec (per
> getdesign.md). Source of truth: `src/tokens/tokens.json`. Version 2.0.0 — **v2 Premium, Official
> since 2026-09-02 (BRAND-DECISION-2026-09-01)**; canon: `docs/brand/TOKENS-v2.json`. See ADR-0026
> for the v1→v2 consolidation rationale.

---

## 1. Identity

**Gentle-Vanguard** is a native AI cognitive development ecosystem. Apps should feel like the same
family — same palette, same typography, same signature, same anti-AI-slop craft.

**v2 Premium (Official since 2026-09-02, BRAND-DECISION-2026-09-01)**: dark institutional-premium
language — background `#0f1115`, cyan `#22d3ee` primary accent, purple `#a78bfa` secondary accent,
refined glass surfaces, Space Grotesk display, outExpo-lite motion. The v3 "Kinetic Premium"
candidate is archived (Design Hub > Labs) and is NOT the brand.

- **Mode**: Operate (visitor completes a task) for most surfaces. Persuade for landing pages.
- **Voice**: Technical, calm, professional. Avoid hype. Avoid "Generated by AI" tells.
- **Mascot**: The `GV` monogram (purple→cyan gradient). Used in wordmark, favicon, headers.
- **Anti-patterns explicitly banned**: cream/terracotta, near-black/acid-green, broadsheet
  hairlines, em-dash overuse, decorative grids, "Taste the future" copy, "Seamless" copy, vague
  "AI-powered" copy.

## 3. Typography

### 3.1 Type families (local-first, no external webfonts)

| Role                              | Family                                                     | Weight  | Letter-spacing     |
| --------------------------------- | ---------------------------------------------------------- | ------- | ------------------ |
| **Display** (logo, banners)       | Space Grotesk, Orbitron (fallback), sans-serif             | 700     | 0.1em              |
| **Body** (UI, content)            | Inter, Inter Variable, system-ui, sans-serif               | 400-700 | normal to -0.025em |
| **Mono** (data, code, CLI)        | JetBrains Mono NL, JetBrains Mono, Cascadia Code, Consolas | 400-700 | normal             |
| **Mono accent** (labels, metrics) | Space Mono, monospace                                      | 400-700 | normal             |

Display font is **Space Grotesk** (official v2, BRAND-DECISION-2026-09-01); Orbitron remains only as
a fallback. The system declares the family and falls back to OS fonts. Never load Inter or Space
Grotesk from Google Fonts; if present, use them, otherwise fall back gracefully.

### 3.2 Type scale (use Text component variants)

| Variant     | Size             | Weight | Use case                          |
| ----------- | ---------------- | ------ | --------------------------------- |
| `display-1` | 3rem (48px)      | 700    | Splash screens, app titles        |
| `display-2` | 2.25rem (36px)   | 700    | Section dividers                  |
| `heading-1` | 1.875rem (30px)  | 800    | Page titles                       |
| `heading-2` | 1.5rem (24px)    | 800    | Section titles                    |
| `heading-3` | 1.25rem (20px)   | 700    | Card titles                       |
| `body`      | 1rem (16px)      | 400    | Body text                         |
| `body-sm`   | 0.8125rem (13px) | 400    | Captions, hints                   |
| `caption`   | 0.75rem (12px)   | 400    | Metadata                          |
| `eyebrow`   | 0.75rem (12px)   | 700    | Section labels (uppercase, 0.2em) |
| `code`      | 0.8125rem (13px) | 400    | Inline code (mono, with bg)       |
| `metric`    | 1.875rem (30px)  | 700    | KPI numbers (mono)                |

### 3.3 Line-height & rhythm

- Body: `1.65` (relaxed)
- Headings: `1.35` (snug)
- Display: `1.2` (tight)
- Eyebrows/captions: `1.0` (no wrap)

## 7. Motion

### 7.1 Durations

| Token                 | Value | Use                                     |
| --------------------- | ----- | --------------------------------------- |
| `gv-duration-instant` | 100ms | Micro feedback (press, toggle)          |
| `gv-duration-fast`    | 180ms | Hover, focus, color transitions         |
| `gv-duration-base`    | 280ms | View transitions, fade-in, slide-up     |
| `gv-duration-slow`    | 400ms | Modals, drawers                         |
| `gv-duration-epic`    | 800ms | Hero/page-level reveals (use sparingly) |

### 7.2 Easing

| Token              | Value                            | Use                                          |
| ------------------ | -------------------------------- | -------------------------------------------- |
| `gv-ease-out`      | `cubic-bezier(0, 0, 0.2, 1)`     | Enter animations                             |
| `gv-ease-in-out`   | `cubic-bezier(0.4, 0, 0.2, 1)`   | State changes                                |
| `gv-ease-smooth`   | `cubic-bezier(0.16, 1, 0.3, 1)`  | Default v2 motion (smooth out)               |
| `gv-ease-out-expo` | `cubic-bezier(0.19, 1, 0.22, 1)` | Premium reveals (outExpo-lite, v2 signature) |

**NEVER** use bounce/elastic easing. Period. It is banned by the impeccable detector as AI slop. The
DS does not export a bounce token. If you need delight, use a different mechanism (subtle scale,
gentle overshoot via `--gv-ease-out` on a small range).

### 7.3 Reduced motion

`@media (prefers-reduced-motion: reduce)` collapses all durations to `0.01ms`. Mandatory in every
app.

### 7.4 Key animations

- `viewIn` (280ms, opacity 0→1 + translateY 8px→0) — view transitions
- `fadeIn` (200ms, opacity 0→1) — toasts, banners
- `slideUp` (280ms, translateY 16px→0) — modals, drawers
- `scaleIn` (150ms, scale 0.95→1) — popovers, tooltips

## 8. Background atmosphere

Every app's `<body>` has 3 fixed layers (z-index: -2, -1, base):

```css
body::before,
body::after {
  content: '';
  position: fixed;
  inset: 0;
  pointer-events: none;
  z-index: -1;
}

body::before {
  /* Grid pattern: 48px tiles, violet + cyan lines at 4.5% opacity */
  background-image:
    linear-gradient(rgba(168, 85, 247, 0.045) 1px, transparent 1px),
    linear-gradient(90deg, rgba(0, 191, 255, 0.045) 1px, transparent 1px);
  background-size: 48px 48px;
  z-index: -2;
}

body::after {
  /* Purple radial glow, top-right, 720px */
  background: radial-gradient(circle, rgba(168, 85, 247, 0.16), transparent 65%);
  width: 720px;
  height: 720px;
  top: -340px;
  right: -220px;
}
```

The grid is intentional brand signature. The detector `codex-grid-background` is waived for this
layer (see `.impeccable/config.json`).

## 10. Components (canonical patterns)

### 10.1 Button

```jsx
<Button variant="primary" size="md" onClick={...}>Save</Button>
<Button variant="secondary" iconLeft={<Icon />}>Cancel</Button>
<Button variant="danger" loading>Deleting...</Button>
<Button variant="ghost" size="sm">Skip</Button>
```

| Variant     | Use case                               |
| ----------- | -------------------------------------- |
| `primary`   | The one obvious action (gradient pill) |
| `secondary` | Alternative actions (cyan outline)     |
| `ghost`     | Tertiary, navigation, low-emphasis     |
| `danger`    | Destructive actions (red)              |

### 10.2 Card

```jsx
<Card variant="glass" padding="md">Default card</Card>
<Card variant="solid" padding="lg">Solid card</Card>
<Card variant="outline" interactive>Clickable card</Card>
```

- `glass` (default): backdrop-blur + violet border (brand signature)
- `solid`: flat surface
- `outline`: transparent with border
- `interactive`: adds hover lift + cyan focus

### 10.3 Input

```jsx
<Input label="Email" type="email" required />
<Input label="Password" error="Too short" />
<Input label="Search" iconLeft={<SearchIcon />} hint="Press Enter to search" />
<Input label="Username" success="Available" />
```

Built-in a11y: `htmlFor`, `aria-describedby` for hint/error, `aria-invalid` on error.

### 10.4 Stack

```jsx
<Stack direction="row" gap={4} align="center" justify="between">
  <Logo />
  <Title>Dashboard</Title>
  <Button>Action</Button>
</Stack>
```

Thin flexbox wrapper with token-based gap scale. Use this instead of raw CSS flex.

### 10.5 Text

```jsx
<Text variant="heading-1">Dashboard</Text>
<Text variant="eyebrow" color="accent">Section label</Text>
<Text variant="metric" color="gradient">99.9%</Text>
<Text variant="code">npm install gv-design-system</Text>
```

Use `Text` for ALL text rendering. Type scale + color tokens enforced.

### 10.6 Tag

```jsx
<Tag variant="success">Active</Tag>
<Tag variant="warning" icon={<Icon />}>Pending</Tag>
<Tag variant="primary" size="sm">Beta</Tag>
```

### 10.7 IconButton

```jsx
<IconButton icon={<SearchIcon />} aria-label="Search" />
<IconButton icon={<CloseIcon />} variant="primary" aria-label="Close" />
```

Always requires `aria-label` (TypeScript enforces it via interface).

## 13. Anti-patterns (banned)

These will be caught by `impeccable detect` (the design linter):

| Anti-pattern                            | Why banned                | Brand waiver?                                        |
| --------------------------------------- | ------------------------- | ---------------------------------------------------- |
| `codex-grid-background`                 | Generic AI tells          | **YES** — grid is brand signature                    |
| `gradient-text`                         | Decorative, vague         | **YES** — wordmark "Vanguard" uses it                |
| `side-tab-border`                       | Most recognizable AI tell | **YES** — lesson-row + content cards use border-left |
| `bounce-easing`                         | Toy-like, unprofessional  | NO                                                   |
| `purple-gradient-on-dark` (overused)    | Generic AI tells          | NO                                                   |
| `pure-black-text-on-pure-white`         | Eye strain, lacks depth   | NO                                                   |
| `tiny-body-text` (<14px)                | Accessibility violation   | NO                                                   |
| `cramped-padding` (<8px around content) | Cognitive load            | NO                                                   |
| `monotonous-spacing`                    | No rhythm                 | NO                                                   |
| `long-line-length` (>80ch)              | Reading fatigue           | NO                                                   |
| `small-touch-target` (<44x44px mobile)  | Mobile UX violation       | NO                                                   |
| `em-dash-overuse` (>2 per paragraph)    | AI writing tell           | NO                                                   |
| `pure-gray-on-colored-bg`               | Contrast violation        | NO                                                   |

## 14. Accessibility (WCAG 2.2)

- **Contrast**: All text ≥ 4.5:1 against its background. Tested with
  `impeccable detect --scope type`.
- **Touch targets**: ≥ 44x44px on mobile. `IconButton` defaults to 36x36 desktop, scales to 44x44 on
  mobile via media query.
- **Keyboard**: All interactive elements reachable via Tab. Focus ring
  (`outline: 3px solid var(--gv-cyan)`) on `:focus-visible`.
- **Screen readers**: `aria-label` required for icon-only buttons. `aria-invalid` +
  `aria-describedby` on form errors.
- **Reduced motion**: `@media (prefers-reduced-motion: reduce)` collapses all transitions.

- **Default**: Dark mode. Always.

## 16. i18n

- Default: English (`en`).
- Spanish (`es`), Portuguese (`pt`) supported via `localStorage gv-cc-lang`.
- i18n tokens live in `i18n.tsx` per app. Never hardcode strings in components.
- Date/time: ISO 8601 in logs, locale-aware in UI.
- Numbers: locale-aware with `Intl.NumberFormat`.

## 17. AI agent integration

This package exposes its tokens and components via:

1. **`@gentle-vanguard/design-system`** (npm package, in monorepo)
2. **`gv-design-system` MCP server** (stdio, `npx tsx packages/gv-design-system/src/mcp/server.ts`)
3. **`gv-design-system` skill** (`.agents/skills/gv-design-system/`, cross-tool: opencode, codex,
   copilot, antigravity, etc)
4. **DESIGN.md** (this file) — the human-readable source of truth

AI agents should:

- Read `DESIGN.md` first to understand the system.
- Use the `gv-design-system` skill for component generation.
- Run `impeccable detect` after generating UI to catch anti-patterns.
- Run `playwright-cli snapshot` + screenshot to verify visual output.

## 18. Versioning

- **Major** (v1 → v2): breaking token changes, removed components.
- **Minor** (v2.0 → v2.1): new components, new tokens, no removals.
- **Patch** (v2.0.0 → v2.0.1): bug fixes, copy edits.

Currently: **2.0.0-alpha.1** — first alpha of v2. Use in `apps/gv-analytics` for trial. Promote to
stable after 1 sprint of usage without critical issues.
