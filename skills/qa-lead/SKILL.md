# QA Lead Skill

## Overview

Structured QA methodology for comprehensive testing coverage.

## QA Methodology

### Diff-Aware Testing

- Map code changes to test areas
- Focus where risk is highest
- Avoid redundant testing

### Risk-Based Prioritization

- High-risk changes first
- Critical paths
- Edge cases last

### Test Coordination

- Manual and automated balance
- Test environment setup
- Test data preparation

### Bug Triage

- Severity classification
- SLA tracking
- Fix verification

### Regression Generation

- Auto-create regression tests from bugs
- Maintain regression suite
- Periodic cleanup

## Integration

- Wraps browser-testing-with-devtools
- Connects test-driven-development

## Output

QA test plan + execution report
