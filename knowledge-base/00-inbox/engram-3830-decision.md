# Estrategia: eBooks como lead magnets de venta

**What**: Decisión estratégica de producto: los eBooks de Academy son la estrategia de venta (lead magnets) para atraer personas, estudiantes y empresas. NO se promueven a cursos completos.

**Why**: El usuario lo confirmó explícitamente: "los ebook no se van a promover a curso completo, es la estrategia de venta, de poder llegar y llamar la atención de personas, estudiantes y empresas".

**Where**: apps/academy-web/data/ebooks/ (7 ebooks: 6 micro + 1 premium)

**Learned**: El funnel de Academy es: eBooks (gancho/atracción) → Cursos (conversión/profundidad) → Toolkit (bundles completos). Los micro-ebooks de 20-40 páginas son contenido de entrada accesible; el ebook premium (80-150 págs) es el producto de mayor valor; los Toolkits combinan todo (curso + ebook + prompts + plantillas + emails + automatizaciones + casos). Esta jerarquía debe mantenerse: no canibalizar los ebooks convirtiéndolos en cursos.
