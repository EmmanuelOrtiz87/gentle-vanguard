- Palette harmony
- Contrast ratios
- Semantic meaning

### Layout

- Spacing
- Alignment
- Grid usage

### Components

- Consistency
- States coverage
- Accessibility

### Motion

- Subtlety
- Purpose
- 60fps performance

### AI-Slop Detection

- Over-polished look
- Generic patterns

- Stock feel
