# Operating Procedures

This directory stores day-to-day operational procedures: command references, update procedures,
Engram maintenance, hook setup, and stack synchronization.

Runbooks with incident response or production behavior belong one level up in `docs/operations/`.

- `MODEL-PROVIDER-HEALTH-RUNBOOK.md` — OpenCode custom provider failure recovery, LiteLLM/Bedrock
  tool-calling notes, and provider validation commands.
