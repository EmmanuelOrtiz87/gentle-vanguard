## 🚀 INSTRUCCIONES DE USO

### Acceder al Sistema

```bash
# Opción 1: Landing principal
open docs/presentations/index.html

# Opción 2: Directo al CMS
open docs/presentations/resources-index.html

# Opción 3: Tools individuales
open docs/presentations/image-studio.html
open docs/presentations/video-studio.html
# etc.
```

### Procesos Documentados

1. **Generar Imagen**
   - Abrir Image Studio
   - Seleccionar template
   - Ingresar prompt
   - Click Generar
   - Auto-guardado en localStorage
   - Exportar o usar Asset Manager

2. **Exportar Proyecto**
   - CMS Dashboard → Descargas
   - Click "Exportar Todo"
   - Descarga ZIP con todo el proyecto

3. **Navegación Bidireccional**
   - index.html → Click "CMS Dashboard"
   - CMS → Tools individuales
   - Tools → Back button al CMS
