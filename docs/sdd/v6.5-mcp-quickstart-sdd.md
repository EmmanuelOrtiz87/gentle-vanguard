# Software Design Document — v6.5: MCP Quickstart / Templates

**Version:** 6.
**Date:** July 7, 202
**Prerequisites:** v6.4 MCP Native (registry, manager, gateway)

## 1. Overview

MCP Native (v6.4) gave the stack the ability to register and manage MCP servers. But the user
still needs to know what servers exist and how to configure them. v6.5 adds **pre-built templates**
that users enable with one command.

### Templates

| Template    | Server                                      | Use case                       |
| ----------- | ------------------------------------------- | ------------------------------ |
| `sqlite`    | `@modelcontextprotocol/server-sqlite`       | Local database queries         |
| `filesystem`| `@modelcontextprotocol/server-filesystem`   | File read/write/search         |
| `memory`    | `@modelcontextprotocol/server-memory`       | Persistent knowledge graph     |
| `browser`   | `@playwright/mcp`                           | Headless browser automation    |
| `git`       | `@modelcontextprotocol/server-git`           | Git operations                 |

## 2. Architecture

### New action in mcp-manager.ps1

```
-Action quickstart -Template <name> [-Path <dir>] [-DbPath <path>]
```

- Reads template definition from `config/mcp-templates.json`
- Resolves paths relative to workspace root
- Registers the server via existing `register` action
- Starts the server if `-Start` flag is set

### Template definitions (`config/mcp-templates.json`)

```json
{
  "version": "1.0.0",
  "templates": [
    {
      "name": "sqlite",
      "description": "Local SQLite database via MCP",
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sqlite", "--db", "{path}"],
      "defaultPath": ".session/data/mcp-sqlite.db",
      "transport": "stdio"
    }
  ]
}
```

### Implementation

1. `config/mcp-templates.json` — template definitions (5 templates)
2. `mcp-manager.ps1` — add `-Action quickstart` and `-Action list-templates`
3. Watchtower — add template config check
4. SDD, CHANGELOG, VERSION, ROADMAP

## 3. Usage

```powershell
# List available templates
.\scripts\utilities\MCP\mcp-manager.ps1 -Action list-templates

# Enable SQLite with default path
.\scripts\utilities\MCP\mcp-manager.ps1 -Action quickstart -Template sqlite

# Enable browser automation with custom path
.\scripts\utilities\MCP\mcp-manager.ps1 -Action quickstart -Template browser -Start

# Verify
.\scripts\utilities\MCP\mcp-manager.ps1 -Action health
```
