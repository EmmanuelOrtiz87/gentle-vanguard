# Software Design Document (SDD) — v6.7: Knowledge Persistence Layer

**Version:** 6.7
**Date:** July 7, 2026
**Status:** PROPOSE
**Prerequisites:** v4.0 (tracing, state-persistence, audit, event-sourcing)

## 1. Vision & Problem

### Vision

> Una sola interfaz para consultar toda la memoria persistente del workspace: engram, event-store,
> traces, feedback, checkpoints.

### Problem Statement

Hoy cada sistema de persistencia tiene su propia CLI y formato:
- **Engram**: `mem_search` — memoria semántica de sesiones
- **Event Store**: `event-sourcing.ps1 -Action project` — eventos de dominio
- **Traces**: `.telemetry/traces/` — spans OpenTelemetry
- **Feedback**: `.session/feedback/` — feedback de usuarios
- **Checkpoints**: `checkpoint-manager.ps1 -Action list` — snapshots de sesión

No hay forma unificada de preguntar "¿qué pasó con el feature X?" a través de todos estos sistemas.

## 2. Architecture

### Unified Query CLI

```
scripts/utilities/knowledge/knowledge-query.ps1 -Query "<text>" [-Sources @("engram","events","traces","feedback","checkpoints")] [-Limit 20] [-TimeRange "-7d..now"] [-Format json|text]
```

### Arquitectura

```
knowledge-query.ps1
  ├── Source: Engram → mem_search nativa
  ├── Source: Events → event-sourcing.ps1 -Action project -AggregateId <query>
  ├── Source: Traces  → walk .telemetry/traces/*.jsonl, grep + filter by time
  ├── Source: Feedback → walk .session/feedback/*.json
  └── Source: Checkpoints → checkpoint-manager.ps1 -Action list | Where-Object { $_.description -like "*<query>*" }
```

### Unified Result Schema

```json
{
  "query": "<original query>",
  "sources": ["engram", "events", "traces"],
  "total": 42,
  "results": [
    {
      "source": "engram",
      "id": "obs-xxx",
      "title": "...",
      "content": "...",
      "timestamp": "2026-07-07T12:00:00Z",
      "relevance": 0.95
    }
  ]
}
```

### Dashboard Endpoint

`GET /api/knowledge?q=<query>&sources=engram,events&limit=10`

Returns unified results as JSON for the dashboard Knowledge panel.

### Knowledge Panel (Dashboard)

- New route `/knowledge`
- Search bar + source checkboxes
- Results list with source badge (color-coded)
- Expandable detail view
