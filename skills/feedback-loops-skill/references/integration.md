## Integration & Verification

### Combining with Other Skills

| Skill | Integration |
|-------|-------------|
| First Principles | Decompose loops into fundamental causal mechanisms |
| Premortem | Stress-test loop interventions for unintended consequences |
| Root Cause | Use loops to understand systemic vs. proximate causes |
| Decision Trees | Map loop-informed decisions as branching paths |
| Cognitive Biases | Identify bias-reinforcing loops (confirmation bias R-loop) |

### Verification Checklist

- [ ] Each loop has a clear label (R-name or B-name)
- [ ] Loop polarity verified by counting (−) signs
- [ ] Delays mapped with estimated duration
- [ ] Dominant loop identified with rationale
- [ ] At least one intervention at Meadows level 1-6 considered
- [ ] Unintended effects traced through secondary loops
- [ ] Intervention testable (small, observable, adjustable)

### Debugging Common Mistakes

| Mistake | Fix |
|---------|-----|
| Missing a key stock | List all accumulations that matter |
| Wrong polarity | Trace: "if A goes up, does B go up or down?" |
| Ignoring delays | Estimate min/max delay for every material flow |
| Only R loops | Look for goals, constraints, corrections |
| Only B loops | Look for self-amplifying dynamics |
| Over-complex | Start with 3-5 variables; expand only if needed |
