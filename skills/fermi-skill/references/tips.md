# Tips for Better Estimates

## Use Multiple Approaches
Estimate the same thing different ways. If methods agree within 3x, confidence increases. If they diverge wildly, investigate assumptions.

## Bound First
Start with extremes: "Definitely more than X, definitely less than Y." Then narrow from there.

## Watch for Correlated Errors
Avoid factors that both depend on the same assumption. Estimate revenue directly instead of Users × Revenue/User if both rely on the same growth assumption.

## One Significant Figure
47,832,519 bytes → report as ~50 MB, not "47.8 MB". Don't fake precision.
