# Security Documentation

This area stores security policy, hardening notes, usage examples, and security improvement records
that are still relevant to the stack.

Generated scan outputs and one-off audit artifacts belong in `reports/` or `.archive/`, not here.

## Runbooks

- [Manual de remediación manual](MANUAL-REMEDIATION-RUNBOOK.md): revocación/rotación de
  credenciales, controles de GitHub, publicación segura, validación de alertas y clasificación de
  históricos.
