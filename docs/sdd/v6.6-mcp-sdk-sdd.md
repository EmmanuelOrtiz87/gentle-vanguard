# Software Design Document (SDD) — v6.6: MCP SDK / Scaffolder

**Version:** 6.6 **Date:** July 7, 2026 **Status:** PROPOSE **Prerequisites:** v6.4 MCP Native, v6.5
MCP Quickstart/Templates

## 1. Vision & Problem

### Vision

> Cualquier desarrollador puede crear un servidor MCP en su lenguaje preferido con un solo comando.

### Problem Statement

v6.5 tiene `mcp-manager.ps1 -Action create` que solo genera boilerplate TypeScript. Para adoptar MCP
como estándar de extensibilidad, necesitamos soporte multi-lenguaje (Python, JavaScript, Go, Rust) y
eliminar los pasos manuales posteriores (npm install, build, register).

## 2. Architecture

### Extended `-Action create`

```
-Action create -Name <name> -Lang <ts|js|py|go|rs> [-Build] [-Register] [-Start]
```

| Flag        | Default  | Description                                        |
| ----------- | -------- | -------------------------------------------------- |
| `-Lang`     | `ts`     | Language for scaffold: ts, js, py, go, rs          |
| `-Build`    | `$false` | Run build after scaffold (npm install/pip install) |
| `-Register` | `$false` | Auto-register in mcp-registry.json                 |
| `-Start`    | `$false` | Start the server after register                    |

### Scaffolders por lenguaje

| Lang | SDK Package                 | Entry point    | Build command        |
| ---- | --------------------------- | -------------- | -------------------- |
| ts   | `@modelcontextprotocol/sdk` | `src/index.ts` | `npm install && tsc` |

<!-- REF-OBSOLETA: src/index.ts no existe (ruta migrada o eliminada) -->

| js | `@modelcontextprotocol/sdk` | `index.js` | `npm install` | | py | `mcp` (PyPI) | `server.py`
| `pip install -e .` | | go | `github.com/mark3labs/mcp-go` | `main.go` | `go mod tidy && go build`
| | rs | `rust-mcp-sdk` | `src/main.rs` | `cargo build` |

### Auto-register

Si `-Register` se pasa, el script:

1. Crea el scaffold
2. Hace build si `-Build`
3. Registra en `config/mcp-registry.json` con `type: "user"`
4. Inicia el server si `-Start`

## 3. Implementation Plan

1. Extender `mcp-manager.ps1` `create` action con switch por `-Lang`
2. Agregar scaffolders:
   - **ts** (existente) — mejorar con `-Build -Register`
   - **js** — plain JavaScript con package.json y MCP SDK
   - **py** — Python con `mcp` SDK, setup.py + server.py
   - **go** — Go module con `mcp-go`, main.go
   - **rs** — Rust project con Cargo.toml, src/main.rs
3. Agregar lógica `-Build` por lenguaje
4. Agregar lógica `-Register` (reusa `register` action existente)
5. Actualizar watchtower con check de scaffolder
6. VERSION → 6.6.0, CHANGELOG, ROADMAP, build, watchtower

## 4. Acceptance Criteria

- [ ] `-Action create -Name test-ts -Lang ts` genera TypeScript scaffold funcional
- [ ] `-Action create -Name test-py -Lang py` genera Python scaffold funcional
- [ ] `-Action create -Name test-go -Lang go` genera Go scaffold funcional
- [ ] `-Action create -Name test-js -Lang js -Build` genera + instala dependencias
- [ ] `-Action create -Name test-rs -Lang rs` genera Rust scaffold
