# Model Router

Domain + Problem Type → Model. Start here to find the right mental model.

## Domain Table

| Domain              | Description                                     |
| ------------------- | ----------------------------------------------- |
| Coding/Debugging    | Bugs, errors, performance, root cause           |
| Architecture        | System design, technical decisions, scalability |
| Product             | Features, user needs, prioritization, roadmap   |
| Business Strategy   | Competition, growth, market, organization       |

## Domain Maps

### Coding & Debugging

Bug unknown → Scientific Method, 5 Whys Plus | Performance → ToC, Systems Thinking | Postmortem → 5
Whys Plus | Flaky → Scientific Method

### Architecture

Tech choice → Lindy Effect, Reversibility | Build vs buy → Opportunity Cost, First Principles |
Scalability → Systems Thinking, Leverage Points | Micro/monolith → Cynefin, Reversibility | API
tradeoffs → TRIZ | Rewrite → Second-Order, Opp Cost

### Product

What to build → Jobs to be Done | Prioritization → Opp Cost, ToC | Engagement → Jobs to be Done, 5
Whys | New product → Effectuation, First Principles | Pivot → Regret Min, Reversibility | PMF → Jobs
to be Done, Scientific Method | A/B test → Scientific Method, Bayesian

### Business Strategy

Competitive → Red Team, Second-Order | Market entry → Cynefin, Effectuation | Growth → Feedback
Loops, Leverage Points | Org dysfunction → Archetypes, Systems Thinking | Resources → ToC, Opp Cost
| Startup → Effectuation, Margin of Safety | Pricing → First Principles, Fermi

### Personal & Career

Job offer → Regret Min, Reversibility | Career → Circle of Competence, Regret Min | Life decision →
Regret Min, Pre-mortem | Learning → Circle of Competence, Lindy | Negotiation → Steel-manning, Red
Team | Startup → Effectuation, Margin of Safety, Pre-mortem | Time → Opp Cost, ToC

### Abstract & Analytical

Evaluate argument → Steel-manning, Bayesian | Challenge assumptions → First Principles, Socratic |
Estimate → Fermi, Probabilistic | Update beliefs → Bayesian | Edge cases → Thought Experiment,
Inversion | Logical flaws → Inversion, Steel-manning | Causation → Systems Thinking | Philosophy →
Thought Experiment, First Principles

### Risk & Safety

What goes wrong → Pre-mortem, Red Team | Security → Red Team, Inversion | Disaster → Pre-mortem,
Margin of Safety | Avoid failure → Margin of Safety, Via Negativa | Failure probability →
Probabilistic, Bayesian | Resilience → Via Negativa, Margin of Safety

### Innovation

Breakthrough → First Principles, TRIZ | Contradictions → TRIZ | Limited resources → Effectuation,
Via Negativa | Simplify → Via Negativa, Occam | Impossible → First Principles, TRIZ | New market →
Effectuation, Jobs to be Done
