# Data Storytelling for Slides

Turn raw data into compelling visual narratives.

## Quick Reference

See `references/` for details on each topic.

### Core Principles

- **Data Without Story Is Just Numbers** — narrative over raw data
- **Show the Relationship** — comparison is the foundation of insight
- **Maximize the Data-Ink Ratio** — remove non-data pixels
- **5-Second Rule** — audience must grasp insight in 5 seconds → `references/core-principles.md`

### Chart Selection (Quick)

| Relationship                            | Chart                  |
| --------------------------------------- | ---------------------- |
| Change over time                        | Line chart             |
| Part of whole                           | Stacked bar / Pie (≤5) |
| Ranking                                 | Horizontal bar         |
| Distribution                            | Histogram / Box plot   |
| Correlation                             | Scatter plot           |
| Progress to goal                        | Bullet chart / Gauge   |
| Flow / Funnel                           | Sankey / Funnel        |
| → `references/chart-selection-guide.md` |

### Maturity Model

Target **Level 3** (Annotated) for internal, **Level 4** (Narrative) for exec presentations. →
`references/maturity-model.md`

### Data Story Structure

**Act 1**: Context → **Act 2**: Insight → **Act 3**: Implication →
`references/actionable-guidance.md`

### Data-Ink & Pre-Attentive

Maximize data-ink; use color/size/position for instant insight (under 500ms). →
`references/data-ink-ratio.md`, `references/pre-attentive-attributes.md`

### Dashboard & Annotations

Hero KPI + trend + sparkline; annotate ONE insight per chart. →
`references/dashboard-slide-design.md`, `references/annotated-charts.md`

### Avoiding Traps

Truncated Y-axis, 3D charts, pie >5 slices, no narrative, data overload, no source. →
`references/misleading-visuals.md`, `references/data-citations.md`

### Static vs Interactive

Static for live presentations/email/PDF; interactive for data rooms/internal reports. →
`references/interactive-vs-static.md`

### Common Mistakes

Chart junk, wrong chart type, missing context, no narrative, data overload, misleading scales, no
source, over-highlighting, small fonts, no takeaway title. → `references/common-mistakes.md`
