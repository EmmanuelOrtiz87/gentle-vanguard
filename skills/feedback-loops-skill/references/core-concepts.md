## Core Concepts

### Reinforcing Loops (R)

Self-amplifying feedback that accelerates change in one direction. Growth, collapse, and compound effects.

- **R1 - Growth**: More users → more value → more users (network effect)
- **R2 - Erosion**: Lower quality → fewer users → less revenue → lower quality
- **R3 - Addiction**: Short-term fix → relief → dependency → more short-term fixes

Sign: Behavior accelerates exponentially (or collapses to zero).

### Balancing Loops (B)

Self-correcting feedback that moves a system toward a target or equilibrium.

- **B1 - Thermostat**: Gap detected → action reduces gap → gap shrinks → action stops
- **B2 - Inventory**: Stock too high → reduce orders → inventory drops → order more
- **B3 - Fatigue**: Work too hard → exhaustion → breaks needed → work slows

Sign: Behavior oscillates around a goal or stabilizes at a set point.

### Delays

Time between cause and effect. Delays create oscillation and instability.

- Perception delay: time to notice a change
- Response delay: time to act once noticed
- Material delay: time for action to take effect

**Rule**: The longer the delay relative to the rate of change, the more the system will overshoot and oscillate.

### Loop Dominance

Multiple loops exist simultaneously. Which one dominates determines behavior.

- Dominance shifts when relative strengths of loops change
- Interventions often aim to weaken a dominant R loop or strengthen a B loop
