Acerca de Gentle-Vanguard

Gentle-Vanguard es un stack autonomo de orquestacion multi-agente disenado para maximizar la productividad del desarrollo de software mediante IA. Combina un motor de ejecucion hibrida (TypeScript/PowerShell) con un sistema de monitoreo en tiempo real, trazabilidad distribuida, y un ecosistema extensible de 33+ skills especializados.

FrontendReact + TypeScript + Vite
BackendNode.js + WebSocket
ScriptsTypeScript + PowerShell
CloudAWS + Azure Connectors
TracingOpenTelemetry OTLP
StorageSQLite + JSONL

Descripcion de las 6 Capas

  • Layer 1 Presentation: Interfaces de usuario incluyendo Dashboard React, CLI hibrido, y WebSocket para streaming en tiempo real
  • Layer 2 Orchestration: Tres orquestadores especializados que manejan seguridad, adaptacion de perfiles y coordinacion de equipos multi-agente
  • Layer 3 Core Services: Sistema de skills con routing basado en embeddings, tracking de uso y base de conocimientos integrada
  • Layer 4 State Persistence: Arquitectura de event sourcing con sagas, checkpoints automaticos y capacidad de rollback
  • Layer 5 Cloud Infrastructure: Ejecucion hibrida cloud-local con tracing OpenTelemetry y export OTLP a localhost:4318
  • Layer 6 Security Governance: 60 health checks, pipeline de auditoria SOC2/GDPR, y safety guardrails para IA

Infraestructura v4.0 - Componentes Clave

  • Cloud Connectors: Hybrid Executor con routing inteligente por costo/latencia/load. AWS y Azure Delegators con circuit breaker 5 failures OPEN, 2 successes HALF_OPEN CLOSED
  • State Persistence: Checkpoint automatico lazy, snapshots manuales, rollback con dry-run validation. Almacenado en .session/checkpoints/ y .session/snapshots/
  • Event Sourcing: Append/project/snapshot/prune en .session/event-store/. Sagas para transacciones distribuidas con compensacion
  • Distributed Tracing: OpenTelemetry con export OTLP a http://localhost:4318/v1/traces. Spans en .telemetry/spans/ y .telemetry/traces/
  • Audit Pipeline: Log/status/query/archive/prune. Almacenamiento JSONL diario en .session/audit/logs/. Cumple SOC2/GDPR

Flujo de Conversacion con el Usuario

  • Pre-Process Input: Cada turno comienza con pre-process-input.ts que detecta la herramienta AI, analiza contexto y logs el turno
  • Skill Router: Busca skills relevantes basado en contexto actual git branch, archivos modificados, commits recientes
  • SubAgent Delegation: El orquestador delega a subagentes especializados con contexto comprimido 50-150 tokens por skill
  • Engram Integration: Toda la memoria persiste en Engram SQLite con hot/warm/cold tiering y compresion automatica
  • Feedback Loop: Los resultados se almacenan con feedback para mejorar futuras recomendaciones de skills

Arquitectura de Seguridad Multi-Capa

  • Perimeter Security: Autenticacion de owner, GitHub bypass policy, tool detection al inicio de cada sesion
  • Prompt Injection Guard: Proteccion contra ataques de prompt injection con sanitizacion de entrada

Data Flow del Sistema

  • Input Layer: Captura de user input, eventos git, y cambios de archivos
  • Processing: Pre-process input con SHA256 cache TTL 30min, routing de skills, orquestacion
  • Memory Tiering: Hot cache activo, warm 1 dia 90% relevancia, cold archive 7 dias 70%
  • Persistence: Engram SQLite para RAG, JSONL para logs, Telemetry para trazas OTLP
  • Output: Dashboard React con WebSocket, streaming de metricas, ejecucion en cloud
  • Handoff Compression: Compresion automatica del contexto al cerrar sesion para eficiencia
