# SEO Audit Skill

## Overview

Comprehensive SEO analysis and optimization.

## Audit Checklist

### On-page SEO

- [ ] Title tags optimized
- [ ] Meta descriptions
- [ ] Header structure (H1-H6)
- [ ] Content quality and keywords
- [ ] Internal linking

### Technical SEO

- [ ] Site speed
- [ ] Mobile responsiveness
- [ ] Schema markup
- [ ] Crawlability
- [ ] Robots.txt and sitemap

### Off-page SEO

- [ ] Backlink profile
- [ ] Domain authority
- [ ] Social signals

### Content Gaps

- [ ] Keyword opportunities
- [ ] Competitor content gaps
- [ ] Topic clusters

## Tools

- Web crawler for site analysis
- Lighthouse for performance

## Output

SEO audit report with prioritized fixes
