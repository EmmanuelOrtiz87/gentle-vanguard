# Common Mistakes

1. **Chart junk**: 3D effects, excessive gridlines, clip art, useless decorations
2. **Wrong chart type**: Pie charts for 12 categories, line charts for categorical data
3. **Missing context**: Metric without comparison (period-over-period, vs. target, vs. industry)
4. **No narrative**: Charts displayed without explanation or insight
5. **Data overload**: Too many metrics/data points/charts. One insight per slide
6. **Misleading scales**: Truncated Y-axes, inconsistent scales, dual axes implying false
   correlation
7. **No source attribution**: Data without a source is untrustworthy
8. **Highlighting everything**: All bars different colors. If everything is highlighted, nothing is
9. **Small fonts**: Axis labels, legends, annotations too small when projected. Minimum 12pt
10. **No takeaway title**: "Revenue by Quarter" tells what it is, not what to learn
