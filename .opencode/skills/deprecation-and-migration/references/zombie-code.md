# Zombie Code

Zombie code is code that nobody owns but everybody depends on. It's not actively maintained, has no
clear owner, and accumulates security vulnerabilities and compatibility issues.

## Signs

- No commits in 6+ months but active consumers exist
- No assigned maintainer or team
- Failing tests that nobody fixes
- Dependencies with known vulnerabilities that nobody updates
- Documentation that references systems that no longer exist

## Response

Either assign an owner and maintain it properly, or deprecate it with a concrete migration plan.
Zombie code cannot stay in limbo — it either gets investment or removal.
