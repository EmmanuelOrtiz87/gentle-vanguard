# Software Design Document (SDD) — v7.0: Multi-repo Orchestration

**Version:** 7.0 **Date:** July 7, 2026 **Status:** PROPOSE **Prerequisites:** v6.4 MCP Native, v6.6
MCP SDK, v6.0 Cross-Workspace Mesh

## 1. Vision & Problem

### Vision

> Un desarrollador puede registrar servidores MCP en cualquier proyecto local y orquestarlos desde
> un solo punto, usando el mesh de confianza existente.

### Problem Statement

Los servidores MCP son locales al proyecto donde se registran. Un equipo con 3 repositorios
(backend, frontend, tools) necesita:

- Descubrir qué servidores MCP están disponibles en cada repo
- Delegar tareas entre servidores de distintos repos
- Compartir templates y servidores comunes sin duplicar configs

v6.0 tiene `cross-workspace-mesh.ps1` para discovery y delegación entre workspaces, pero no está
integrado con el ecosistema MCP.

## 2. Architecture

### Componentes

```
┌─────────────────────────────────────────────────────────┐
│              Multi-repo Orchestrator                      │
│  ┌──────────────────┐  ┌──────────────────────────────┐  │
│  │ MCP Mesh Scanner  │  │ Unified MCP Gateway           │  │
│  │ (descubre servers │  │ (rutea tools entre repos)     │  │
│  │  en todos los     │  │  por prefijo repo_name)        │  │
│  │  workspaces mesh) │  └──────────────────────────────┘  │
│  └──────────────────┘                                    │
│  ┌──────────────────┐  ┌──────────────────────────────┐  │
│  │ Template Sync     │  │ Dashboard Multi-repo View    │  │
│  │ (comparte         │  │ (servers agrupados por repo) │  │
│  │  templates entre  │  │  con estado global)           │  │
│  │  repos)           │  └──────────────────────────────┘  │
│  └──────────────────┘                                    │
└─────────────────────────────────────────────────────────┘
```

### MCP Mesh Scanner

```
mcp-mesh-scan.ps1
  -Action discover  → escanea workspaces mesh por config/mcp-registry.json
  -Action status    → health check de todos los servers en todos los repos
  -Action sync      → copia templates a todos los repos mesh
```

### Unified MCP Gateway

El gateway existente (`mcp-gateway.ps1`) se extiende para:

- Leer registros MCP de workspaces mesh (vía symlinks o config central)
- Routear tools por prefijo: `repoA/tool-name`, `repoB/tool-name`
- Cachear estado de servers remotos

### Dashboard Multi-repo

- New `/multi-repo` route in dashboard
- Tabla de repos con conteo de servers MCP
- Drill-down a servers por repo
- Start/stop servers remotos (via mesh delegation)
