# Design Review Skill

## Overview

Systematic design audit with 6 dimensions and AI-generated content detection.

## Review Dimensions (Score 0-10)

### Typography

- Hierarchy
- Readability
- Scale consistency

### Color

- Palette harmony
- Contrast ratios
- Semantic meaning

### Layout

- Spacing
- Alignment
- Grid usage

### Components

- Consistency
- States coverage
- Accessibility

### Motion

- Subtlety
- Purpose
- 60fps performance

### AI-Slop Detection

- Over-polished look
- Generic patterns
- No personality
- Stock feel

## Tools

- Browser DevTools
- Design tokens reference

## Output

Design scorecard with improvement recommendations
