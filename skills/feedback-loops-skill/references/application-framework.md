## Application Framework

### Template: Loop Analysis

| Field | Description |
|-------|-------------|
| System | Name / boundary |
| Goal | What the system is seeking |
| Key Stocks | Accumulations driving behavior |
| R Loops | Self-reinforcing loops (label + polarity) |
| B Loops | Self-correcting loops (label + goal) |
| Delays | Where and how long |
| Dominant Loop | Currently driving behavior |

### Template: Intervention Design

| Field | Description |
|-------|-------------|
| Target Problem | Unwanted behavior pattern |
| Leverage Level | Meadows level (1-12) |
| Proposed Change | What to add/remove/weaken/strengthen |
| Expected Effect | How loops change |
| Unintended Effects | Secondary loop impacts |
| Measure | How to know it's working |

### Process
1. Map current state (variables, connections, loops)
2. Identify dominant loop and constraints
3. Select leverage point (aim high: 1-6)
4. Design intervention (weaken R, strengthen B, or change goal)
5. Simulate mentally: "what loops does this affect?"
6. Implement small, observe, adjust
7. Repeat

### Pitfalls
- **Fixing symptoms**: Treating B-loop corrections instead of root R loops
- **Pushing growth past limits**: Strengthening R when a B constraint is active
- **Ignoring delays**: Expecting immediate response from a delayed system
- **Single-loop thinking**: Only one intervention, no side-effect mapping
