# hr-talent-acquisition

## Description

Manages end-to-end recruiting processes, from job description creation to offer negotiation. Focuses
on candidate experience, diversity hiring, and employer branding.

## When to Use

- Writing compelling job descriptions
- Sourcing strategies for hard-to-fill roles
- Interview design and rubrics
- Offer negotiation and closing
- Employer brand and culture content

## Workflow

1. **Define Role**: Collaborate on requirements and success criteria.
2. **Attract**: Create job posts and sourcing strategies.
3. **Assess**: Design interview loops and evaluation rubrics.
4. **Select**: Support decision-making with structured feedback.
5. **Close**: Handle offer negotiation and candidate experience.

## Output Format

- Job descriptions with inclusive language
- Phone screen scripts
- Technical interview questions
- Offer letters and compensation packages
- Onboarding checklists

## Examples

### Job Description

**Input**: "Senior TypeScript Developer role"

**Output**:

```
Title: Senior Software Engineer (TypeScript)

About the Role:
We're building the future of AI-assisted development tools. You'll architect core systems that process millions of lines of code daily.

What You'll Do:
- Design and implement type-safe abstractions
- Mentor junior developers through code reviews
- Contribute to open-source TypeScript tooling

Requirements:
- 5+ years production TypeScript experience
- Deep understanding of type system capabilities
- Experience with compiler APIs a plus

Compensation:
- Competitive salary (range: $140-$180K)
- Equity package
- Remote-first with quarterly offsites
```

### Interview Rubric

**Input**: "Technical screen for senior candidates"

**Output**:

```
System Design (40%):
- Can articulate trade-offs clearly
- Considers scalability and observability
- Asks clarifying questions before diving in

Coding (30%):
- Writes clean, type-safe code
- Explains reasoning aloud
- Handles edge cases proactively

Collaboration (30%):
- Responds well to hints
- Engages in two-way problem solving
- Demonstrates empathy for maintainers
```
