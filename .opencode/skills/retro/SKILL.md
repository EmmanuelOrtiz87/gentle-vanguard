# Retro Skill

## Overview
Data-driven retrospectives using actual session metrics.

## Data Sources
- `.session/` logs
- Nexus DB metrics
- Session scoring

## Retro Format

### What Went Well?
- Wins from the period
- Team strengths demonstrated

### What Could Improve?
- Identified issues
- Root cause analysis

### Action Items
- Owners assigned
- Due dates set

### Shout-outs
- Recognition for contributions
- Team appreciation

## Metrics to Review
- Commits per developer
- Test pass/fail trends
- Token usage patterns
- Session scores

## Template
Retro document with metrics and actions
